# 3D-Modelle (.glb)

Hier liegen die 3D-Modelle für die Ansicht „In 3D ansehen“. Ein Produkt
bekommt ein Modell über das Feld `modelUrl` im Katalog, z. B.
`"modelUrl": "/models/sheen-chair.glb"`.

| Datei | Herkunft | Lizenz |
| --- | --- | --- |
| `sheen-chair.glb` | „SheenChair“ aus den Khronos glTF-Sample-Assets (Wayfair) | CC0-1.0 (gemeinfrei) |

`sheen-chair.glb` ist nur ein **Beispielmodell**, damit die 3D-Ansicht
vorführbar ist — es ist nicht der echte Sessel „Finkenau“. Echte Modelle
kommen vom Lieferanten/Hersteller oder werden pro Produkt erstellt
(Format: glTF-Binary `.glb`, ideal < 5 MB).
